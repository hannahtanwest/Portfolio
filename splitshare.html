SplitShare

Bachelor

Web Development

For my bachelors project in web development, we created SplitShare, a web application that supports structured registration of joint expenses, manual distribution between users, and a comprehensive and clear balance overview. The project's intention was to investigate how concepts from economic modeling and algorithmic processing can be implemented to ensure consistency and transparency in a shared economic system.

The Main Focus

The main focus was to create a system that is based on double bookkeeping. There is a particular focus on backend design, data modeling and computational logic, including how financial transactions can be structured and modeled in a way that reduces errors and ensures that the state of the system remains consistent.

Prototypes in Figma

In the project, we worked directly with low-fidelity wireframes in Figma, where layout, information hierarchy and the most important treatments were represented with simple visual elements and placeholders. Due to the choice of low-fidelity wireframes, it was easy to quickly change the structure and functionality, as the focus is on the basic layout.
